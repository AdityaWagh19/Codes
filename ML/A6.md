# A6: K-Means and Hierarchical Clustering on Sales Data

Dataset: `sales_data_sample.csv`

## Cell 1

```python
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

from sklearn.cluster import KMeans
from sklearn.preprocessing import StandardScaler
```

## Cell 2

```python
df = pd.read_csv("sales_data_sample.csv",
                 encoding='latin1')

df.head()
```

## Cell 3

```python
X = df[['SALES','QUANTITYORDERED']]

scaler = StandardScaler()

X_scaled = scaler.fit_transform(X)
```

## Cell 4

```python
wcss = []

for i in range(1,11):

    kmeans = KMeans(
        n_clusters=i,
        random_state=42,
        n_init=10
    )

    kmeans.fit(X_scaled)

    wcss.append(kmeans.inertia_)
```

## Cell 5

```python
plt.figure(figsize=(8,5))

plt.plot(
    range(1,11),
    wcss,
    marker='o'
)

plt.xlabel("Number of Clusters")
plt.ylabel("WCSS")
plt.title("Elbow Method")

plt.show()
```

## Cell 6

```python
kmeans = KMeans(
    n_clusters=4,
    random_state=42,
    n_init=10
)

clusters = kmeans.fit_predict(X_scaled)

df['Cluster'] = clusters
```

## Cell 7

```python
plt.figure(figsize=(8,6))

sns.scatterplot(
    x='SALES',
    y='QUANTITYORDERED',
    hue='Cluster',
    data=df,
    palette='Set1'
)

plt.title("K-Means Clustering")
plt.show()
```

    X_scaled,
